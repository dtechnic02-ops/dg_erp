# DG ERP — IRD Pre-Submission Checklist

Unchecked items are not complete and must not be represented as complete.

## Technical

- [x] Fiscal compliance foundation implemented
- [x] Compliance regression gate passes
- [x] Evidence package prepared
- [x] Technical documentation prepared
- [x] Synthetic Tax Invoice evidence prepared
- [x] Synthetic Credit Note evidence prepared
- [x] Fiscal Sales Account evidence prepared
- [x] Audit trail evidence prepared
- [x] Auditor role evidence prepared
- [ ] Final IRD technical format review completed

## Legal

- [ ] Final legal company name confirmed
- [ ] Company registration certificate/details supplied
- [ ] Company PAN/VAT certificate/details supplied
- [ ] Registered address confirmed
- [ ] Authorized signatory and authority confirmed
- [ ] Official email and phone confirmed
- [ ] Signature/stamp supplied if required
- [ ] Current IRD application and attachment requirements confirmed

## IRD clarification

- [ ] Written mapping answers received
- [ ] Answers archived with provenance and date
- [ ] Engineering decisions updated from authoritative answers
- [ ] CBMS payload and transport implemented
- [ ] CBMS integration tests completed
- [ ] IRD test/sandbox verification completed

## External review

- [ ] CA accounting/VAT review completed
- [ ] Independent VAPT/security review completed
- [ ] Material findings corrected through separately approved work
- [ ] CA/VAPT retest completed where required
- [ ] Controlled screenshots captured and privacy-reviewed

## Final engineering

- [ ] Final release/version identifier frozen
- [ ] Full regression completed against release candidate
- [ ] Production migration plan reviewed
- [ ] Backup and rollback plan approved and tested
- [ ] Release commit reviewed and created
- [ ] Approved branch pushed
- [ ] Controlled deployment completed

## IRD

- [ ] Application finalized and signed
- [ ] Attachments verified against current IRD requirements
- [ ] Application submitted
- [ ] IRD technical verification completed
- [ ] Requested corrections completed and retested
- [ ] Official software listing/approval received

No submission, deployment, commit, or push is authorized by this checklist.
